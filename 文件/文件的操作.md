# 文件的操作

#### 文件的创建

```shell
touch 文件名
```

如果是多个文件的创建可以后面直接跟上如：

```shell
touch t.txt t2.txt
```



#### 文件的删除

```shell
rm 文件名
```

多个文件的删除跟多个文件的创建类似也是如此.



#### 文夹内容的查看

```shell
cat 文件名
```

#### 文件夹的创建

```shell
mkdir 文件夹 ...
```

多个文件夹的创建跟多个文件的创建一样。

#### 文件夹的删除

```shell
rm -r 文件夹...
```

也可以进行多个文件夹的删除.

#### 文件目录的查看

```shell
ls [路径]
```

后面不跟路径，就显示当前路径下的目录结构。
