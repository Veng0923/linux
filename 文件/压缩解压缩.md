# 压缩和解压缩

#### 常用压缩格式

压缩格式: `.zip`、`.4gz`、`.bz2`、`.tar.gz`、`.tar.bz2`、`.tar.xz`
最常用的是`.tar.gz`格式和`.tar.bz2`格式

---

#### .zip 格式

压缩文件语法：

```shell
zip 压缩文件名 源文件
```

例如：

```shell
zip  test.zip ./test.txt
```

压缩文件夹语法:

```shell
zip -r 压缩文件夹名 源文件夹
```

例如：

```shell
zip test.zip ./test
```

解压缩语法：

```shell
unzip 压缩文件
```

例如：

```shell
unzip test.zip
```

更多的命令可以查看 zip --help,unzip --help.

#### tar 命令

```shell
# 压缩
tar -cvf 打包文件名 源文件
# 解压缩
tar -xvf 打包后的文件名
```

参数说明： `-c` 打包，`-v` 显示过程，`-x` 解包, `-f` 指定打包后的文件.

以上是压缩解压缩，`.tar`后缀的压缩文件.

如果是压缩为` .tar.gz`的压缩文件,则还需要加上参数 `-z `: 压缩为 .tar.gz格式, `-x`解压缩`.tar.gz`格式,还有 `-t` 只查看压缩文件,不解压。

例如：

```shell
# 压缩文件
tar -zcvf 压缩文件名.tar.gz 源文件
# 解压文件
tar -zxvf 压缩文件名 [-C 解压位置]
```
